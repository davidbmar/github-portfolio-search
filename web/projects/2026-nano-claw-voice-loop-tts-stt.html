What it is

nano-claw is a personal AI agent designed for voice interaction. It combines a TypeScript-based agent core with a Python voice server to create a full-duplex voice loop. The system uses Whisper for speech-to-text (STT) running natively on macOS for GPU acceleration, Claude for reasoning, and Piper for text-to-speech (TTS). It supports tool use (shell, file operations) with explicit user approval via the browser interface.

Features

  • Full-duplex voice conversation via WebRTC in the browser
  • Metal-accelerated Whisper STT running natively on macOS for low latency
  • Claude-powered agent loop with persistent memory and skill loading
  • Secure tool execution (shell, file read/write) with browser-based approval cards
  • Local Piper TTS for private, offline-capable speech synthesis
  • Hands-free phone mode with automatic voice activity detection

How it's built

The architecture splits responsibilities between a native macOS process and a Docker container. The STT service runs natively to access Apple's Metal GPU, exposing an HTTP API on port 8200. The main application runs in Docker, containing a TypeScript API server (port 3001) for agent logic and a Python Voice Server (port 8080/9090) handling WebRTC audio streaming and Piper TTS. The browser client connects via WebSocket to the Voice Server, which orchestrates the flow: receiving audio, calling the native STT service, sending text to the TypeScript agent, and streaming back synthesized speech.

How to apply & reuse

Use this project as a template for building local-first voice agents. It demonstrates how to bypass Docker GPU limitations on macOS by sidecar-ing native services. The modular agent loop in TypeScript allows for easy extension of tools and skills, while the Python voice server provides a robust WebRTC bridge for real-time audio processing.
