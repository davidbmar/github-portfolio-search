NVIDIA Parakeet Riva ASR Deployment System

Production-ready deployment of NVIDIA Parakeet RNNT via Riva ASR with WebSocket streaming and comprehensive infrastructure scripts.

https://github.com/davidbmar/nvidia-parakeet-ver-5  ·  public  ·  shipped

What it is

A deployment framework and client wrapper for running NVIDIA's Parakeet RNNT automatic speech recognition model. It supports both modern NIM containers and traditional Riva server setups, providing low-latency streaming transcription via WebSocket with word-level timestamps and confidence scores.

Features

  • Real-time streaming transcription with ~100-300ms partial result latency
  • Dual deployment support for NVIDIA NIM containers and traditional Riva servers
  • Word-level timestamps and confidence scores for precise alignment
  • Production-grade structured logging and monitoring framework
  • WebSocket API for browser and application integration
  • Mock mode fallback for development without GPU hardware

How it's built

Built with Python 3.10+ using FastAPI for the server interface, Pydantic for configuration management, and websockets for real-time audio streaming. It integrates with NVIDIA Riva ASR via gRPC clients, uses SpeechBrain for fallback or alternative modeling, and relies on Docker/NVIDIA Container Runtime for GPU-accelerated inference on Tesla T4/V100 instances.

How to apply & reuse

Deploy on AWS EC2 g4dn.xlarge or similar GPU instances. Use provided bash scripts to configure security groups, install NVIDIA drivers, deploy Riva/NIM containers, and start the WebSocket proxy. Connect client applications (browser or Node.js/Python) to the WebSocket endpoint for real-time transcription.
