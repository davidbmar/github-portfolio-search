Everyone Ai

Self-service AI workspace platform for launching Claude Code environments via Kubernetes.

https://github.com/davidbmar/everyone-ai  ·  private  ·  shipped

What it is

A portal that allows team members to launch pre-configured VS Code workspaces backed by Claude Code in seconds. It manages the lifecycle of workspace pods on a k3s cluster, provides an app catalog for templates, and exposes persistent HTTPS endpoints for deployed targets.

Features

  • Launch Claude Code workspaces in under 30 seconds
  • App Catalog with pre-configured templates like HR Onboarding Agent
  • Monitor and stop personal VS Code environments
  • Deploy running apps as persistent HTTPS endpoints
  • Cross-portal fleet overview for team administrators

Quickstart

npx afterburner bootstrap --host <ip> --ssh-key ~/.ssh/id_rsa
npx afterburner install
helm install everyone-ai-portal ./charts/portal -f profiles/k3s.yaml -f config.yaml --namespace myteam --create-namespace
open https://portal.<your-domain>

How it's built

Built with Node.js and Express for the backend API, vanilla JavaScript for the frontend SPA, and Helm charts for Kubernetes deployment. It uses k3s for the underlying cluster, Traefik for ingress, and code-server for the browser-based IDE experience.

How to apply & reuse

Operators use the 'afterburner' CLI to bootstrap a Linux VM with k3s and deploy the portal via Helm. End users connect via VPN, access the portal URL, select a template from the App Catalog, and launch a workspace to get a ready-to-use Claude Code terminal in their browser.
