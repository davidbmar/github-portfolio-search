Everyone Ai

Self-service AI workspace platform for launching Claude Code environments via Kubernetes.

https://github.com/davidbmar/everyone-ai  ·  private  ·  shipped

What it is

A portal that allows team members to launch pre-configured VS Code workspaces backed by Claude Code in seconds. It manages the lifecycle of workspace pods on a k3s cluster, provides an app catalog for templates, and exposes persistent HTTPS endpoints for deployed targets.

Features

  • Launch Claude Code VS Code workspaces in under 30 seconds
  • App Catalog with pre-configured templates (Python, Node.js, HR Agent)
  • Deploy running apps as persistent HTTPS endpoints (Targets)
  • Team-wide usage monitoring and fleet overview
  • Zero-config setup for users via VPN and browser access

Quickstart

npx afterburner bootstrap --host <ip> --ssh-key ~/.ssh/id_rsa
npx afterburner install
helm install everyone-ai-portal ./charts/portal -f profiles/k3s.yaml -f config.yaml --namespace myteam --create-namespace
open https://portal.<your-domain>

flowchart TD

    Traefik --> Portal[Portal Server Node Express]
    Portal --> K8sClient[Kubernetes Client]
    K8sClient --> WorkspacePods[Workspace Pods code-server]
    K8sClient --> TargetPods[Target Pods user apps]
    WorkspacePods --> ClaudeCode[Claude Code Terminal]
    TargetPods --> HTTPLive[HTTPS Endpoint]

How it's built

Node.js Express backend serving a vanilla JS SPA frontend. Uses the Kubernetes JavaScript client to manage workspace and target pods on a k3s cluster. Traefik handles ingress routing. Deployment is managed via Helm charts and an 'afterburner' CLI tool for bootstrapping infrastructure.

How to apply & reuse

Operators use the afterburner CLI to bootstrap a Linux VM with k3s and deploy the portal via Helm. End users connect via VPN, access the portal URL, select a template from the App Catalog, and launch a workspace to get a browser-based VS Code instance with Claude Code ready in the terminal.
