Phone Number SMS + Vanity Examples

Verified against Telnyx on 2026-07-04. These are example/demo mappings, not a final production allocation.

All four numbers are active local US numbers on the same Telnyx voice connection (chattychapters-phone) and the same enabled messaging profile (RIFF Verify Caller Debug). The messaging profile is enabled and whitelisted for US destinations, so each number is Telnyx-ready to send SMS.

No live outbound test SMS was sent; this is a Telnyx configuration-level verification.

Telnyx can send from each number, but RIFF's current SMS adapter sends from the single global TELNYX_FROM_NUMBER. To make these examples fully branded in-product, add per-dialed-number or per-flow SMS sender selection before calling the Telnyx SMS adapter.

Vanity URLs below are proposed public aliases under https://riff.chattychapters.com. They should redirect to the relevant landing, intake, or follow-along page when implemented; this doc does not mean the redirects are live yet.
