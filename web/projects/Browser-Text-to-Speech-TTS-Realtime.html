Browser Text To Speech TTS Realtime

A zero-server, client-side neural text-to-speech engine using WebAssembly and ONNX for real-time streaming audio.

https://github.com/davidbmar/Browser-Text-to-Speech-TTS-Realtime  ·  public  ·  shipped

What it is

This project is a high-performance React application that performs neural text-to-speech synthesis entirely in the browser. It leverages VITS models compiled to WebAssembly via ONNX Runtime, enabling offline-capable, privacy-first audio generation with multi-core parallel processing and streaming playback without external API dependencies.

Features

  • 100% client-side neural TTS using WebAssembly and ONNX
  • Streaming playback that starts audio before full generation completes
  • Multi-core processing via WebAssembly threads for faster synthesis
  • Offline support with browser-cached voice models in IndexedDB
  • Eight built-in natural voices across English, German, French, and Spanish
  • Privacy-first architecture with no data sent to external servers

Quickstart

git clone https://github.com/davidbmar/Browser-Text-to-Speech-TTS-Realtime.git

How it's built

The frontend is built with React 18, TypeScript, and Vite, styled with Tailwind CSS and shadcn/ui. The core inference engine uses @diffusionstudio/vits-web to load ONNX models into WebAssembly. Audio processing utilizes Web Workers for multi-threading, while state management relies on React hooks and TanStack Query for data handling. The server component is minimal, primarily serving static assets with COOP/COEP headers to enable SharedArrayBuffer for WASM threads.

How to apply & reuse

Integrate the useTTS hook into any React component to add voice capabilities. Configure voice ID, speed, and volume via options. Use the speak method to trigger audio generation from text strings, leveraging built-in sentence splitting for streaming playback. Monitor progress via returned state properties like isGenerating and chunks to update UI indicators.
