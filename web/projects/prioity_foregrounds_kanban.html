Priority Foregrounds Kanban

A standalone workbench for allocating a fixed 100-point budget across decision principles to deterministically rank product initiatives.

https://github.com/davidbmar/prioity_foregrounds_kanban  ·  public  ·  shipped

What it is

A local-first web application that helps product teams make tradeoffs explicit by distributing a strict 100-point budget across five editable decision principles. It features a deterministic queue ranking system, proportional point redistribution, and an optional AI evaluator that proposes scores based on structured prompts while enforcing strict validation contracts to prevent malformed data injection.

Features

  • Enforces an exact 100-point budget across five principles with a 0.1 floor
  • Deterministic queue ranking based on weighted principle scores
  • Optional AI evaluator proposes complete score columns with concise reasons
  • Strict validation rejects partial, duplicate, or out-of-range AI outputs
  • Retains score history, prompt state, and model provenance in local storage
  • Includes responsive queue comparison view and unit-economics calculator

How it's built

The backend is a Python standard library HTTP server serving static assets and handling AI rescoring via the Gemini API. The frontend is a vanilla JavaScript single-page application managing state in browser local storage. Communication occurs via JSON APIs with strict schema validation, hash-based provenance tracking, and in-memory rate limiting.

How to apply & reuse

Use this tool during product strategy sessions to force explicit prioritization. Define five key principles (e.g., Customer Value, Risk, Leverage), allocate points to reflect current strategic weight, and input your initiative queue. Use the AI rescoring feature to generate evidence-based justifications for each principle, then manually review and accept or reject the proposed scores to maintain human-in-the-loop control.
