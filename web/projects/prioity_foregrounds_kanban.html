Priority Foregrounds Kanban

A local-first workbench for deterministic product prioritization using a fixed 100-point budget across editable decision principles.

https://github.com/davidbmar/prioity_foregrounds_kanban  ·  public  ·  shipped

What it is

A standalone Python web application that helps product teams make tradeoffs explicit by allocating a strict 100-point budget across five customizable decision principles. It features a deterministic queue ranking system, proportional point redistribution, and an optional AI evaluator that proposes scores with strict validation to prevent malformed or partial outputs from affecting the board.

Features

  • Enforces an exact 100-point budget across five editable decision principles with a 0.1 floor
  • Deterministic queue ranking that updates instantly as principle weights change
  • Optional AI evaluator that proposes complete score columns with strict validation and rejection of partial outputs
  • Local storage persistence for scores, reasons, prompt state, and budget provenance
  • Responsive UI with unit-economics calculator and queue comparison view
  • Fail-closed security model with same-origin checks and no HTML injection in model reasons

How it's built

Built with Python 3.11+ using only the standard library for the core server (http.server) and logic. The frontend is vanilla JavaScript, HTML, and CSS. Optional AI integration uses the Google Gemini API via an extra dependency group, with strict in-memory caching, rate limiting, and token budgeting implemented in pure Python.

How to apply & reuse

Use this tool during product strategy sessions to force explicit weighting of decision criteria (e.g., Customer Value vs. Risk). Edit the seed data in web/app.js to reflect your current initiative queue, then use the slider interface to adjust principle weights and observe immediate rank changes. Enable AI rescoring to get structured, evidence-based scoring proposals for specific principles.
