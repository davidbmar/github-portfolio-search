What it is

riff is a Python-based platform for building voice agents that combine Large Language Models (LLMs) for natural language understanding with declared Finite State Machines (FSMs) for strict workflow enforcement. It allows users to describe a business in plain English, automatically generating a YAML-defined flow that handles phone conversations for tasks like scheduling, ordering, and intake. The system ensures reliability by using the LLM only for 'riffing' (language generation) while the FSM 'keeps the beat' (validating slots, enforcing transitions, and preventing hallucinations).

Features

  • Generates voice agent flows from plain English business descriptions
  • Enforces deterministic state transitions using YAML-defined FSMs
  • Prevents LLM hallucinations via strict slot validation and guardrails
  • Includes built-in A/B testing harness for observable metric scoring
  • Supports multiple LLM backends including Gemini, Gemma, and Claude
  • Provides real-time web UI for inspecting live agent sessions

How it's built

The core engine uses a pure-function architecture where guardrails, slot extraction, and state transitions are deterministic. An LLM adapter (supporting Gemini, Gemma, or Claude) processes user intent, but its output is constrained by a StateManager that validates against a declared graph. The system includes an A/B testing harness for observable metric scoring, a web server for real-time inspection, and supports MCP (Model Context Protocol) integration. All non-LLM components are designed as pure functions to ensure reproducibility and ease of testing.

How to apply & reuse

Use riff to rapidly prototype and deploy voice agents for service businesses (plumbing, dental, tutoring) or retail scenarios (coffee, pizza). It is ideal for developers who need the flexibility of LLMs for conversation but require the reliability of state machines for data collection and workflow completion. It can be integrated into existing telephony systems via its API or used as a standalone voice interface.
