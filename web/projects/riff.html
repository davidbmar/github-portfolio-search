What it is

riff is a Python-based voice agent framework that combines Large Language Models for natural language understanding with declared Finite State Machines (YAML) for strict workflow enforcement. It allows developers to describe a business process in plain text, automatically generating a voice agent that handles phone conversations for tasks like scheduling, ordering, and intake. The system ensures reliability by using pure functions for guardrails, slot validation, and state transitions, preventing LLM hallucinations while maintaining conversational fluidity.

Features

  • Generates voice agent flows from plain English business descriptions
  • Enforces strict state transitions and slot validation via YAML-defined FSMs
  • Deterministic guardrails and pure function validators prevent LLM hallucinations
  • Supports multiple LLM backends including Gemini, Gemma, and Claude
  • Built-in A/B testing harness using observable metrics without live LLM judges
  • Real-time web UI for monitoring active sessions and FSM states

How it's built

The core architecture separates the 'riffing' LLM layer from the 'beat-keeping' FSM layer. Incoming speech is converted to text via STT, then processed by `run_turn()`, which consults a `StateManager` enforcing a declared YAML graph. Guardrails (8 layers of pure functions) validate inputs before they reach the LLM or state transition logic. The system supports multiple LLM adapters (Gemini, Gemma, Claude) and includes deterministic fallbacks for slot extraction. Observability is built-in via JSONL logging and silent-failure tracking.

How to apply & reuse

Use riff to build robust customer service voice agents for specific verticals like plumbing, dental clinics, or retail. Define your business logic in a YAML flow file or generate one via the API using a natural language description. Integrate the generated agent into your telephony stack via the provided web server or MCP interface. It is ideal for scenarios requiring high reliability and structured data collection (slots) where pure LLM agents might drift or hallucinate.
