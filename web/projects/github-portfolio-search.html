GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, Web UI, and MCP server. It enables developers to find reusable code patterns and architectures across their own portfolio.

Features

  • Client-side semantic search using TF-IDF and embeddings
  • Automated repository indexing and README extraction
  • Faceted filtering by language, tech stack, and stars
  • MCP server integration for AI agent access
  • Auto-generated capability clusters and related repos
  • Static web UI deployable to S3/CloudFront

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Built with Python for the indexing pipeline (using sentence-transformers and SQLite-vec), FastAPI for the REST API, and static HTML/JS for the client-side web UI. Deployment uses AWS S3, CloudFront, and Lambda functions for OAuth and logging.

How to apply & reuse

Clone the repo, configure a GitHub Personal Access Token, index your repositories using the CLI, and serve the web UI or deploy to AWS. AI agents can connect via the MCP server to search your codebase programmatically.
