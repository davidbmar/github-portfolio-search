GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, web UI, and MCP server. It allows developers to find reusable code patterns and architectures across their own portfolio.

Features

  • Client-side semantic search using TF-IDF and embeddings
  • Auto-clustering of repos into capability categories
  • MCP server integration for AI agent access
  • Faceted filtering by language, tech stack, and stars
  • Automated weekly reindexing via GitHub Actions
  • Exportable search results and embeddable widgets

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Python backend with FastAPI for REST services, SQLite-vec for vector storage, sentence-transformers for embeddings, and a static HTML/JS frontend. Deployment uses AWS S3, CloudFront, and Lambda for OAuth/logging. Indexing is automated via GitHub Actions.

    API-->>WebUI: Return search results
    WebUI-->>Client: Display results with snippets

How to apply & reuse

Clone the repo, configure a GitHub token, index your repositories using the CLI, and serve the web UI or integrate the MCP server into AI agents like Claude Code for context-aware code discovery.
