GitHub Portfolio Search

Semantic search engine for personal GitHub portfolios with AI agent integration

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories using embeddings and TF-IDF to enable semantic search, faceted filtering, and capability clustering. It exposes data via a static web UI, a REST API, and an MCP server for AI agents.

Features

  • Semantic search using embeddings and TF-IDF across READMEs and code
  • Auto-clustering of repos into capability categories like Voice or AI
  • MCP server for AI agents to search portfolio programmatically
  • Faceted filtering by language, tech stack, and star count
  • Static web UI with shareable URLs and localStorage collections
  • Automated weekly reindexing via GitHub Actions

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Python backend using sentence-transformers for embeddings and SQLite-vec for vector storage. The indexing pipeline fetches repo metadata and READMEs via GitHub API. The web UI is a static HTML/JS application consuming JSON exports. Deployment uses AWS S3, CloudFront, and Lambda for OAuth.

How to apply & reuse

Use it to quickly find reusable code patterns across your own projects. Integrate the MCP server into AI coding assistants like Claude Code to let them discover relevant context from your portfolio without loading all code into context. Embed the widget on personal sites.
