GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a semantic search interface via CLI, REST API, and static web UI. It enables developers to find reusable code patterns across their own portfolio.

Features

  • Semantic search using embeddings and TF-IDF across READMEs
  • Auto-clustering of repos into capability categories
  • Static web UI with faceted filtering and autocomplete
  • MCP server for AI agent integration
  • Weekly automated reindexing via GitHub Actions
  • Exportable search results and shareable URLs

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Python backend with FastAPI for serving data, SQLite-vec for vector storage, sentence-transformers for embeddings, and a static HTML/JS frontend. Indexing is handled by a Python pipeline triggered by GitHub Actions or CLI.

How to apply & reuse

Clone the repo, configure a GitHub token, index your repositories using the CLI, and serve the web UI or deploy to S3/CloudFront. Use the MCP server to allow AI agents to search your portfolio.
