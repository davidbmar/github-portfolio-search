GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, Web UI, and MCP server. It allows developers to find reusable code patterns and architectures across their own portfolio.

Features

  • Semantic search using embeddings and TF-IDF across READMEs and code
  • Auto-generated capability clusters and related repo recommendations
  • Client-side web UI with faceted filtering and autocomplete
  • MCP server integration for AI agent access
  • Automated weekly reindexing via GitHub Actions
  • Exportable search results and shareable URLs

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Built with Python for the indexing pipeline (using sentence-transformers and SQLite-vec), FastAPI for the REST API, and static HTML/JS for the client-side web UI. Deployment uses AWS S3, CloudFront, and Lambda functions for OAuth and logging.

How to apply & reuse

Use it to quickly locate specific implementation patterns, boilerplate, or documentation within your own historical projects without manually browsing repositories. Integrate it with AI agents via MCP to provide context-aware code retrieval.
