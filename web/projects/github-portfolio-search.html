GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, Web UI, and MCP server. It allows developers to find reusable code patterns and architectures across their own portfolio.

Features

  • Semantic search using embeddings and TF-IDF weighting
  • Auto-clustering of repositories into capability categories
  • MCP server integration for AI agent access
  • Static web UI with faceted filtering and autocomplete
  • Automated weekly reindexing via GitHub Actions
  • Exportable search results and shareable URLs

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Python backend using sentence-transformers for embeddings and SQLite-vec for vector storage. FastAPI serves the REST API. The web frontend is static HTML/JS consuming JSON exports. AWS Lambda handles OAuth and logging. GitHub Actions automate weekly reindexing.

How to apply & reuse

Use the CLI to index your repos, then search via command line or deploy the static web UI to S3/CloudFront. Integrate with AI agents via the MCP server to allow them to query your codebase contextually.
