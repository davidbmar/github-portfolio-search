GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, web UI, and MCP server. It helps developers find reusable code patterns and architectures across their own portfolio.

Features

  • Semantic search using embeddings and TF-IDF across READMEs and code
  • Auto-generated capability clusters and related repo suggestions
  • CLI, Web UI, and MCP server interfaces for AI agents
  • Faceted filtering by language, tech stack, and stars
  • Automated weekly reindexing via GitHub Actions
  • Exportable search results and embeddable widget

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
# Edit .env to add GITHUB_TOKEN
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Python backend with FastAPI for the REST API, SQLite-vec for vector storage, sentence-transformers for embeddings, and a static HTML/JS frontend. Indexing is handled by a Python pipeline triggered locally or via GitHub Actions. Deployment uses AWS S3 and CloudFront.

How to apply & reuse

Clone the repo, install dependencies, configure a GitHub token, index your repos, and serve the web UI or use the CLI/MCP server to search your codebase semantically.
