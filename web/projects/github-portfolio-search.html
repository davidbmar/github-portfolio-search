GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, REST API, and static web UI. It enables developers to find reusable code patterns and architectures across their own portfolio using natural language queries.

Features

  • Semantic search using embeddings and TF-IDF across READMEs and code
  • Faceted filtering by language, tech stack, and star count
  • Auto-generated capability clusters and related repo suggestions
  • CLI, REST API, and static web UI interfaces
  • MCP server integration for AI agent access
  • Automated weekly reindexing via GitHub Actions

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Built with Python for the indexing pipeline (using sentence-transformers and SQLite-vec) and FastAPI for the REST API. The web frontend is static HTML/JS served from S3/CloudFront. AWS Lambda functions handle OAuth and logging. GitHub Actions automate weekly reindexing.

    GitHubActions->>IndexingPipeline: Trigger index job
    IndexingPipeline->>GitHubAPI: Fetch repos and READMEs
    GitHubAPI-->>IndexingPipeline: Return repo data
    IndexingPipeline->>SQLiteVec: Update embeddings and index

How to apply & reuse

Clone the repo, install dependencies, configure a GitHub token, index your repos, and serve the web UI or use the CLI. Deploy to AWS S3/CloudFront for production use. Integrate with AI agents via the MCP server.
