GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, REST API, and static web UI. It enables developers to find reusable code patterns and architectures across their own portfolio using natural language queries.

Features

  • Semantic search using embeddings and TF-IDF across READMEs and code
  • Auto-clustering of repositories into capability categories
  • Static web UI with faceted filtering and autocomplete
  • CLI tool for indexing, searching, and exporting data
  • MCP server integration for AI agent access
  • Automated weekly reindexing via GitHub Actions

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Built with Python for the indexing pipeline (using sentence-transformers and SQLite-vec) and FastAPI for the backend. The frontend is a static HTML/JS application served from S3/CloudFront. Indexing is automated via GitHub Actions. Authentication uses Google OAuth via AWS Lambda. Data is stored in SQLite and JSON files.

How to apply & reuse

Clone the repo, install dependencies, configure a GitHub token, index your repos, and serve the web UI or use the CLI. Deployable to AWS S3/CloudFront for public access. Integrates with AI agents via MCP server.
