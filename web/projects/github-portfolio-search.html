GitHub Portfolio Search

Semantic search engine for personal GitHub repositories using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, REST API, and static web UI. It enables developers to find reusable code patterns and architectures across their own portfolio using semantic similarity and keyword matching.

Features

  • Client-side semantic search using TF-IDF and embedding vectors
  • Automatic clustering of repositories into capability categories
  • Faceted filtering by language, tech stack, and star count
  • MCP server integration for AI agent access to portfolio data
  • Static site generation with shareable URLs and export options
  • Weekly automated reindexing via GitHub Actions

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Built with Python for the indexing pipeline (using sentence-transformers and SQLite-vec), FastAPI for the optional REST backend, and vanilla HTML/JS for the client-side search UI. Data is exported as static JSON files for hosting on S3/CloudFront. Authentication uses GitHub OAuth via AWS Lambda.

How to apply & reuse

Clone the repo, install dependencies, configure a GitHub token, index your repositories, and export data for the web UI or serve via the local API. Deployable to AWS S3/CloudFront for public access or runnable locally for private use.
