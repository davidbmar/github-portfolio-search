GitHub Portfolio Search

Semantic search engine for personal GitHub portfolios using embeddings and TF-IDF.

https://github.com/davidbmar/github-portfolio-search  ·  public  ·  shipped

What it is

A tool that indexes GitHub repositories, extracts README content, generates embeddings, and provides a searchable interface via CLI, Web UI, and MCP server. It enables developers to find reusable code patterns and architectures across their own projects.

Features

  • Semantic search using embeddings and TF-IDF across READMEs and code
  • Auto-clustering of repositories into capability categories
  • MCP server integration for AI agents to search portfolio
  • Client-side web UI with faceted filtering and autocomplete
  • Automated weekly reindexing via GitHub Actions
  • Exportable data formats (JSON/Markdown) and embeddable widgets

Quickstart

git clone https://github.com/davidbmar/github-portfolio-search.git
cd github-portfolio-search
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
ghps index <your_github_username>
ghps export
cd web && python3 -m http.server 8000

How it's built

Built with Python for the indexing pipeline (using sentence-transformers and SQLite-vec), FastAPI for the REST API, and static HTML/JS for the client-side web UI. Deployment uses AWS S3, CloudFront, and Lambda functions for OAuth and logging. GitHub Actions automate weekly reindexing.

How to apply & reuse

Clone the repo, install dependencies, configure a GitHub token, index your repositories, and serve the web UI or use the CLI/MCP server to search your codebase semantically.
